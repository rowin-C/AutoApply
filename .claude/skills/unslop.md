# unslop — Cut AI tells from any writing. Must always apply.

Process: Scan patterns → rewrite to "Preserve meaning, match intended tone" → self-audit: "What makes this obviously AI generated?" → fix.

Content: delete/expand "-ing phrases" (Rule 3); delete vague attributions (Rule 4).
Language: replace AI vocab (delve, pivotal, showcase, intricate → plain); "serves as" → "is"; skip "Not just X, but Y"; avoid forced triples; pick one noun; list topics (no false ranges).
Style: ban em dashes; colons only for lists; limit bold; convert bold-label headers to prose; sentence-case headings; strip emojis; straight quotes.
Artifacts: drop chatbot phrases; drop sycophantic tone; respond directly.
Filler: "In order to" → "To"; cut hedging; replace generic conclusions with specifics.
Jargon: swap abstract metaphors (substrate, wedge, vector, nexus, gold-plating, ratchet) for concrete words (base, add, way, more than needed).
Plain speech: name mechanisms/numbers; split dense sentences; active voice; stronger verbs; plain synonyms (utilize → use); drop mannered metaphors; full sentences with articles.
